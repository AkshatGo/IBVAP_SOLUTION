# IBVAP — core dependencies
#
# Deliberately light: this is the file Streamlit Community Cloud installs,
# and its free tier cannot fit torch + ultralytics + easyocr (~2.5GB).
# web_demo.py is written to degrade gracefully — it falls back to OpenCV's
# HOG person detector when ultralytics is absent, and skips OCR when
# easyocr is absent — so the hosted demo runs on this set alone.
#
# For the full edge pipeline, training scripts and tests, also install
# requirements-ml.txt (or just run `make install`).

# Core
# OpenCV is pinned below 5.0 deliberately: OpenCV 5 removed HOGDescriptor
# (and CascadeClassifier), and the hosted demo's no-torch fallback path
# depends on HOG. web_demo.py degrades further to motion detection if it
# ever runs on 5.x anyway, but 4.x is the tested surface.

opencv-python-headless>=4.8.0,<5.0
